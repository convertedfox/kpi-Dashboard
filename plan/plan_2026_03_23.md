# KPI-Dashboard V1 mit JSON-Source-of-Truth und periodischem Excel-Import

## Summary
- V1 liefert ein read-only Streamlit-Dashboard in `main.py`, optimiert für Management-Übersicht plus Projektdetail mit KPI-Zeitverlauf.
- Die bestehende Excel-Datei dient nur zum Bootstrap von Stammdaten und initialen Werten; der operative Datenstand liegt anschließend in `data/kpis.json`.
- Neue KPI-Stände kommen über eine definierte deutschsprachige Excel-Vorlage.

## Key Changes
- Datenmodell mit `Project`, `KPIDefinition`, `MeasurementRecord` und einem JSON-Dokument als Source of Truth.
- Bootstrap-Skript baut das initiale JSON aus `plan/Projektbericht Innovationsprojekte.xlsx`.
- Template-Generator erstellt eine deutschsprachige Excel-Vorlage für genau eine Berichtsperiode.
- Importer liest nur diese Vorlage, validiert strikt und schreibt atomar in das JSON.
- Dashboard bietet Portfolio-Übersicht, Gruppenfilter, Projektfilter und KPI-Zeitverläufe.

## Public Interfaces / Types
- Persistenzformat: `data/kpis.json`
- Importvorlage mit den Spalten `Berichtsperiode`, `Projekt-ID`, `Projektname`, `KPI-ID`, `KPI-Name`, `Einheit`, `Wert`, `Kommentar`
- CLI für Bootstrap, Template-Erzeugung und Import

## Test Plan
- Parser-Test für das Bootstrap-Workbook
- Validierungstests für Perioden und Wertetypen
- Import-Tests für gültige und ungültige Vorlagen
- Aggregations- und Filtertests für die Dashboard-Logik

## Assumptions
- Kein Auth- oder Mehrbenutzerbetrieb in V1
- Berichtsperioden sind in V1 halbjährlich (`H1`/`H2`)
- Dashboard bleibt read-only; Datenpflege läuft über Vorlage plus Importer
